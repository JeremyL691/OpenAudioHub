## Dashboard

The Dashboard is the first page after you sign in. Three tiles sum up your library, and each one opens the matching list:

- **Last 7 days**: how many recordings came in this week and how much audio they hold.
- **Not transcribed**: recordings that still need a transcript.
- **Processing**: recordings the audio pipeline is working on, with the state of the first one.

Below the tiles are your latest recording and the eight most recent ones. While Plaud or an AI provider is not set up yet, a **Set up** checklist links to the settings you still need.

## Library and collections

**Library** lists every recording, grouped by day, newest first. Each row shows a small waveform, the duration, when it was recorded, where it came from (Plaud or an upload), and its status. Select a row to preview it on the right, or choose **Open full view** for the whole page.

The sidebar's **Collections** narrow the library:

| Collection | Shows |
| --- | --- |
| Starred | Recordings you starred |
| Last 7 days | Recordings from the past week |
| From Plaud | Recordings synced from your Plaud account |
| Uploaded | Files you uploaded and recordings you merged |

The filter above the list (All, Transcribed, Processing, Untranscribed) works inside the current collection. To star a recording, use the star next to its title, or **Star** in its actions menu.

## Search

The search field in the library matches titles and transcript text. On other pages, the search field in the toolbar opens the library with the results. In the library, press `⌘K` for the command palette, which finds recordings and runs actions.

## A recording

The player stays docked at the bottom of the window on large screens. The transcript lists each segment with its start time: click a time to play from there, and turn on **Follow playback** to keep the current segment in view. The summary, with key points and action items, sits beside the transcript on wide windows and behind the **Summary** tab otherwise.

## Keyboard shortcuts

Press `?` anywhere to see them all.

| Keys | Action |
| --- | --- |
| `⌘K` | Command palette |
| `/` | Focus search |
| `j` / `k` | Next / previous recording |
| `Space` | Play or pause |
| `←` / `→` | Seek back / forward 5 seconds |
| `,` | Open settings |
