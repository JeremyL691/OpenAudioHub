title: Install

On an Apple Silicon Mac, the [Mac app (beta)](/docs/self-hosting/desktop) runs without Docker.

## Prerequisites

- Docker with Compose v2.
- A Plaud account with at least one recorder.
- A transcription provider. Use an API key from an OpenAI-compatible provider, Google Gemini, or ElevenLabs, or run a local model server such as Ollama or LM Studio. Browser transcription needs no provider.

## One-line installer

The installer checks for Docker and Compose, downloads the release files, generates the secrets, and starts the stack in `$HOME/openaudiohub`.

```bash
curl -fsSL https://github.com/JeremyL691/OpenAudioHub/releases/latest/download/install.sh | sh
```

To pin a release, use the installer from that release:

```bash
curl -fsSL https://github.com/JeremyL691/OpenAudioHub/releases/download/v1.0.0/install.sh | sh
```

When the containers are healthy, open `http://localhost:3000` and create an account. The setup steps connect your Plaud account and choose a transcription provider.

## Manual setup

To manage the files yourself, download the compose file and the environment template from the release:

```bash
mkdir openaudiohub && cd openaudiohub
curl -fLO https://github.com/JeremyL691/OpenAudioHub/releases/latest/download/docker-compose.yml
curl -fL https://github.com/JeremyL691/OpenAudioHub/releases/latest/download/env.example -o .env
```

Edit `.env`. Set `POSTGRES_PASSWORD`, `BETTER_AUTH_SECRET`, `ENCRYPTION_KEY`, `AUDIO_PIPELINE_TOKEN`, and `APP_URL`. Generate each secret separately with `openssl rand -hex 32`. Then start the stack:

```bash
docker compose up -d
```

## Check the stack

```bash
docker compose ps
curl http://localhost:3000/api/health
```

The health endpoint returns `"status":"ok"` when the app is ready.
