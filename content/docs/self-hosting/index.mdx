OpenAudioHub runs on infrastructure you control. The stack is a web app with Postgres, plus an optional audio pipeline for long recordings. This section covers the operator's tasks. If you only use an existing installation, the guides cover what you need.

## Where to start

- **[Install](./install)**: the one-line installer, or a manual Compose setup.
- **[Environment variables](./environment-variables)**: every setting, with defaults and the values you must set.
- **[S3-compatible storage](./storage-s3)**: store audio in AWS S3, Cloudflare R2, MinIO, Backblaze B2, or anything S3-compatible.
- **[Email (SMTP) setup](./email-smtp)**: let the email notification backend deliver mail.
- **[Upgrading](./upgrading)**: image tags, upgrades, rollbacks, and what to back up first.

## Not here

Per-user settings, such as connecting a Plaud account, choosing AI providers, enabling notifications, and exporting data, are covered in the [guides](/docs/guides/connect-plaud-account).
